# Statix Whitepaper

Tokens meet art on Solana.

## Vision

A token should be more than a ticker and a chart. Statix imagines a Solana where every project carries a recognisable face: a set of artwork that holders can collect, display and rally around.

## Mission

Make it simple for a project to pair its token with its own NFT set, and for people to discover, follow and join those projects from one place.

## Roadmap

### Phase 1: Foundation

- Launch the Statix site and the live Solana radar
- Publish the contract address and official channels
- Confirm and publish the figures reserved on the site

### Phase 2: Pairing

- Release the first token and NFT set pairing
- Open the step-in and step-out routes
- Document the terms for holders

### Phase 3: Projects

- Let outside teams create their own pairs
- Add perks and rewards that projects can switch on
- Ship builder tooling

### Phase 4: Living sets

- Artwork that evolves with its crowd
- Events and shared experiences around each set
- Tools for communities to steer their own sets
